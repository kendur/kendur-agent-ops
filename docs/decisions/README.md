# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for the KenDur Agent Operations project.

## What is an ADR?

An ADR documents a significant decision: what was decided, why, and what alternatives were considered. Once accepted, an ADR is not edited—it is superseded by a new ADR if the decision changes.

## Status values

- **Proposed** — under discussion, not yet accepted
- **Accepted** — in effect
- **Superseded by ADR-XXXX** — replaced by a later decision
- **Rejected** — considered and not adopted
