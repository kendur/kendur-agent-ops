# Security

## Scope

This is a documentation-only repository. It contains no application code, credentials, or sensitive personal data.

## Reporting a concern

If you discover something in this repository that raises a security or privacy concern—such as accidentally committed credentials or personally identifying information—please open a private issue or contact the maintainer directly rather than opening a public issue.

## What does not belong here

- API keys, tokens, or credentials of any kind
- Personal data covered by privacy regulations
- Internal or confidential business information

If you find any of the above in this repository, please report it immediately.

## AI output

Agent-generated reports and observations stored in `reports/` and `data/` must not contain credentials, personal data, or proprietary information from third parties. Any such content found in agent output should be reported and removed before it is committed.
