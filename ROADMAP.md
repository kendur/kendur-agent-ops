# Roadmap

This roadmap tracks planned milestones for the KenDur Agent Operations repository. It reflects intent, not commitment. Items move to [`CHANGELOG.md`](CHANGELOG.md) once complete.

## Now — Foundation

- [x] Define repository structure and purpose
- [x] Document operating principles
- [x] Establish agent charters for four initial roles
- [x] Define communication and reporting standards
- [x] Define evidence and source policy
- [x] Capture origin context in history documents
- [x] Record initial architecture decisions (ADR-0001 through ADR-0004)

## Next — Agent Readiness

- [ ] Draft and review agent prompts for each role
- [ ] Validate output schemas against real examples
- [ ] Define escalation thresholds for each agent
- [ ] Establish baseline change-detection criteria per data source
- [ ] Produce first example observation and report records

## Later — Operational

- [ ] Activate agents in a read-only, draft-output mode
- [ ] Establish review cadence for agent output
- [ ] Decide on automation platform (human decision required)
- [ ] Decide on storage mechanism (human decision required)
- [ ] Add a license once the appropriate type is determined

## Deferred

- Production agent implementation (belongs in a separate repository)
- Application code for the Executive Support System
- Database schema design
